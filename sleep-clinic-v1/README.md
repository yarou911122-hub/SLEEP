# 睡眠門診個案管理系統 V1

這是第一步的醫護人員前台原型，使用原生 HTML、CSS、JavaScript。無須安裝套件、登入帳號或啟動後端。

## 1. 開啟專案

1. 若下載 ZIP，請先「解壓縮全部」，不要在壓縮檔內直接開啟。
2. 進入 `sleep-clinic-v1` 資料夾，雙擊 `index.html`，使用 Edge 或 Chrome 開啟。
3. 看見左側「睡眠門診」與右側首頁即代表成功。
4. 修改檔案並存檔後，重新整理瀏覽器即可查看更新。

本版不使用網路字型、外部套件或 API，可離線開啟。沒有登入、權限或正式資料保護功能，請勿輸入真實個資或醫療資料。

## 2. 檔案用途

```text
sleep-clinic-v1/
├── index.html          頁面外框、左側導覽、載入樣式與程式
├── css/
│   └── styles.css      低彩度灰綠配色、表格、卡片與手機版面
├── js/
│   ├── mock-data.js    四筆虛構個案與固定示範日期
│   └── app.js          切換頁面、搜尋篩選與顯示假資料
└── README.md           執行方式與分階段驗收說明
```

目前是一個 HTML 外框，透過網址的 `#home`、`#cases` 等片段切換內容，不需另開多個 HTML 檔。先以小型結構降低單人維護負擔，之後可再拆分功能。

## 3. 第一步可以驗收什麼

- 首頁：四張統計卡、當日回診與待辦入口。示範基準日固定為 2026-11-16，不代表電腦的今天。
- 個案管理：以姓名或編號即時搜尋，可搭配狀態篩選；清空搜尋並選擇全部狀態可恢復四筆資料。
- 個案詳細資料：點擊個案姓名或「查看資料」，查看基本資料、下次回診、表單與通知狀態及管理備註。
- 回診管理：瀏覽三筆按日期與時間排序的回診安排。
- 評估表單狀態：查看假資料的待填寫、填寫中與已完成。表單名稱目前為佔位名稱。
- LINE 通知狀態：只顯示假資料，沒有任何實際綁定或發送。
- 瀏覽器的上一頁、下一頁可切換已瀏覽的頁面。
- 縮窄視窗時，側欄改成上方橫向導覽；寬表格可左右捲動。

新增與編輯按鈕目前停用並標示「下一步」，尚未提供表單。所有資料僅讀取自本機假資料檔，未使用 localStorage、資料庫或任何持久保存方式。

## 4. 建議按這個順序試用

1. 開啟首頁：應看到收案總數 4 人、追蹤中 2 人、當日回診 2 人、待完成評估 2 人。
2. 點「個案管理」，搜尋 `DEMO-001`：應只出現示範個案甲。
3. 輸入不存在的名稱：應顯示沒有符合條件的資料。
4. 清空搜尋，選「已結案」：應只出現示範個案丁。
5. 點個案姓名進入詳細資料，再點「返回個案清單」。
6. 逐一切換回診、評估表單、LINE 通知頁，確認頁面標題與側欄選取狀態一致。
7. 嘗試手機寬度與鍵盤 Tab 導覽，確認文字、表格及焦點清楚。

## 5. 後續循序製作與驗收

每一步完成並確認流程後，再進入下一步：

1. **目前：架構與基本頁面**——導覽、假資料、搜尋與個案詳情。
2. **個案新增與編輯**——確認欄位、必填提示、取消與儲存，再加入僅限假資料的瀏覽器保存。
3. **回診管理**——新增、修改與取消安排，補上歷次回診紀錄。
4. **評估追蹤**——先與老師確認表單種類與狀態規則，再加入操作。
5. **通知追蹤**——區分 LINE 綁定與訊息發送狀態，僅模擬流程，不接 LINE API。
6. **V1 整體驗收**——空白資料、搜尋無結果、欄位檢核、手機版面與工作流程檢查。

設計目前以「清單 → 詳細資料 → 回到清單」為主。尚未取得舊版實際畫面與欄位清單，因此只能先保留這個常見管理流程，後續需再對照老師確認的舊版流程調整。
